# Contributing to React Leak Guard

Thank you for your interest in contributing to React Leak Guard! 🛡️

Whether you're fixing a bug, proposing a new feature, or improving documentation, your help is highly appreciated.

## How to Contribute

### 1. Report a Bug or Request a Feature

Before creating a new issue, please check if it already exists in
the [Issues](https://github.com/TSNikita/react-leak-guard/issues) tab. If not, feel free to open a new one with a
clear description and steps to reproduce (for bugs).

### 2. Submit a Pull Request (PR)

1. **Fork** the repository and clone it to your local machine.
2. Create a new branch for your feature or bugfix:
    - For features: `git checkout -b feat/your-feature-name`
    - For fixes: `git checkout -b fix/your-bugfix-name`
3. Make your changes.
4. **Important:** Ensure all tests pass and the code is formatted correctly:

   ```bash
   npm run test:run
   npm run lint:fix

5. Commit your changes with a clear, descriptive message.
6. Push your branch to your fork and open a **Pull Request** to the `main` (or `develop`) branch of this repository.

## Code Style

- We use **TypeScript** with strict mode enabled.
- Code formatting is handled by **ESLint** and **Prettier**. Please do not manually format code; let the tools do it.
- Keep functions small, focused, and well-documented with JSDoc comments.

## Questions?

If you have any questions or need help, feel free to open an issue or reach out via GitHub Discussions.

Thank you for making React Leak Guard better! 🚀
```
